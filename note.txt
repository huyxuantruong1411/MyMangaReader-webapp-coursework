    * **1,762,156** chương thật (`chapters` nạp batch set-based; sinh page manifest lười khi mở đọc), **76** tags, **49,937** tác giả/họa sĩ

- Trang đọc truyện hỗ trợ **Hybrid Page Engine**:
    1) Tự động lấy trang truyện thật từ MangaDex At-Home API (cache đĩa local) khi online
    2) Tự động fallback sang trang truyện demo minh họa WebP nếu chapter hết hạn / offline
- Tính năng ETL/CDC đồng bộ bên thứ ba tạm thời đặt **ON HOLD** (`VITE_EXTERNAL_ETL_ENABLED=false`).

5. CÁC LỆNH DATABASE (MIGRATION, IMPORT DỮ LIỆU LOCAL & RESET)
--------------------------------------------------------------------------------
# Áp dụng migration mới nhất lên DB hiện tại
pnpm db:migrate

# Đồng bộ lại toàn bộ 86,866 truyện, 1.76M chương và địa chỉ MinIO từ `MangaLibrary` vào SQL Server `QL_DocTruyen` (idempotent, không copy file ảnh)
pnpm db:import-local

# (Tùy chọn) Seed chỉ 5 truyện mẫu gọn nhẹ vào DB cấu hình hiện tại
pnpm db:seed

# Xem revision migration hiện tại của DB
pnpm db:current

# Kiểm tra kết nối trực tiếp tới SQL Server `QL_DocTruyen`:
uv --directory apps/api run pytest -m live_mssql

7. XỬ LÝ NHANH MỘT SỐ LỖI THƯỜNG GẶP
--------------------------------------------------------------------------------
1) PowerShell 5.1 báo lỗi toán tử `&&`:
   - Chạy từng lệnh trên từng dòng hoặc dùng dấu `;`.

2) Lỗi cổng 8020 hoặc 5173 đang bị chiếm:
   - Kiểm tra PID: `netstat -ano | findstr :8020` hoặc `findstr :5173`
   - Dừng tiến trình: `taskkill /PID <PID> /T /F`

3) Muốn bật lại giao diện ETL/CDC bên thứ ba sau này:
   - Trong file `.env`, đổi `EXTERNAL_ETL_ENABLED="true"` và `VITE_EXTERNAL_ETL_ENABLED="true"`,
     rồi khởi động lại cả `pnpm dev:api` và `pnpm dev:web`.

4) Muốn tắt MangaDex At-Home fallback (chỉ dùng ảnh trang truyện demo offline 100%):
   - Trong file `.env`, đổi `MANGADEX_FALLBACK_ENABLED="false"` và khởi động lại `pnpm dev:api`.
